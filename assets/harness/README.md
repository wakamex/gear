# Harness logos

The logos the app shows beside a room member's messages, one for each agent harness gear knows: `claude.svg`, `codex.svg`, `gemini.svg`, `agy.svg` (Antigravity), `opencode.svg`, `devin.svg`, `zcode.svg` (Z.ai), `muse.svg` (Meta's mark, as Muse Code has none of its own) and `endchat.svg`.

All but endchat's are from [Lobe Icons](https://github.com/lobehub/lobe-icons) 1.106.0 (`@lobehub/icons-static-svg`, MIT, `LICENSE-lobe-icons.txt`), the coloured version where there is one: `claude-color`, `codex-color`, `gemini-color`, `antigravity-color`, `devin-color`, `meta-color`, and `opencode` and `zai`, which are one colour. The marks are their owners' trademarks. endchat has no logo; `endchat.svg` is Wakterm's tab-bar icon for it, from the polygon in `wakterm-gui/src/customglyph.rs`.

`tools/harness-icons` renders them to `assets/avatars/harness-NAME.png`, 96 px, the one-colour ones in the app's text colour.
